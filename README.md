## Agent X.PLODE
Agent XPLODE is a fast paced, physics based puzzle FPS about a secret agent with a not-so-secret weapon. Use your rocket launcher to propel yourself through handcrafted levels, keep your spot as the Agency’s go-to guy, and explode everything that isn’t nailed down.
